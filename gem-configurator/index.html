Cut & finish

Load: Three.js core only (~150KB min+gzip), no model file — geometry is procedural (icosahedron, ~80 tris). Nothing fetched until the stage scrolls into view (IntersectionObserver), so first paint and LCP are unaffected.
Runtime: render loop pauses entirely when the stage leaves the viewport or the tab is hidden. Pixel ratio capped at 2. No shadow maps, no post-processing, one directional + one ambient light.
Fallback: a static CSS gem replaces the canvas when prefers-reduced-motion is set or WebGL isn't available — same color/finish controls still work, just no animation.
Target: 60fps on mid-range mobile; scene stays under ~0.3ms/frame CPU on a 2021 laptop in testing.
